# 학생 성적 분석 사이트 — 구현 계획

## Context (왜 만드는가)
우리 학교 교사가 한 학년 전 교과의 수행평가·중간·기말 성적 파일을 넣으면, 학생 개인이
자기 학습을 점검하고 교사는 학급을 진단하도록 돕는 내부용 도구. 이름은 쓰지 않고
학년·반·번호와 점수만 사용. 반/번호는 임의 코드로 대체.

### 교육학 원칙 (탭 분리의 근거)
- 학생에게는 **다른 학생과 비교하는 서열형 차트 금지** (Karaman 2021 메타분석: 학생 주도 자기점검이 효과 큼 / 서열 노출은 저성취 학생의 학습 포기 위험). 학생 화면은 **자기 대비 진전** 프레이밍만.
- 분포·상자그림·문항분석 같은 진단 차트는 **교사의 다음 수업 결정용** → 교사 탭에만.
- 참조: [[학생의 자기 데이터 점검과 목표설정]], [[형성평가]], [[성적 분포 기술통계]], [[데이터 기반 의사결정]], [[문항분석]].

## 확정된 결정
| 항목 | 결정 |
|---|---|
| 구조 | 정적 사이트 + 로컬 빌드 (엑셀→JSON). 라이브 서버 DB 없음 |
| 탭 | **교사 탭 / 학생 탭 분리** (탭 토글) |
| 학생 탭 | 자기 대비 진전 위주 + **5등급 뱃지만 참고 표시**. 전체 분포·위치·석차·백분위 숨김 |
| 교사 탭 | 진단 차트(히스토그램·상자그림·5등급 분포). **간단 비밀번호 게이트** |
| 등급 | 상대 석차등급 5등급 (누적 10/34/66/90/100%), 과목별 산정 |

| 문항분석·루브릭 | **phase 2** (문항별/기준별 데이터 필요, 지금은 총점 기반만) |
| 차트 | Chart.js (+ box plot 플러그인, annotation 플러그인) |
| 디자인 | 클레이모피즘, 주색 `#036242` 계열, **이모지 금지 → 인라인 SVG만** |
| 디자인 문서 | `docs/design.md` |

## 아키텍처
```
data/            # 교사가 넣는 원본 엑셀 (배포 안 됨)
  국어.xlsx  수학.xlsx  체육.xlsx ...
config/
  subjects.json  # 과목별 요소·반영비율·만점
scripts/
  build-data.mjs # xlsx 파싱(SheetJS) → 등급·도달률·분포 계산 → 산출물
  grade.mjs      # 5등급 컷 + 도달률 순수함수 (단위 테스트 대상)
src/
  index.html  main.js  style.css  charts.js
  icons/         # 인라인 SVG (이모지 대체)
docs/
  plan.md  design.md
dist/            # 배포물 (정적)
```

### 데이터 분리 (프라이버시)
- `public/data/students.json` — **코드별 본인 데이터만** (과목별 요소 도달률·총점·5등급). 코호트 분포 없음 → 학생 탭이 남의 데이터를 안 받음.
- `public/data/cohort.json` — 교사 탭용 과목별 분포(라벨 없는 총점 배열, 상자그림 통계). **비밀번호 입력 후 로드**.
- `code-map.csv` — 학년/반/번호↔코드. 교사 오프라인 보관, **배포 안 함**.
- ⚠️ 정적 사이트라 비밀번호는 우발적 노출 차단용이지 완전 보안 아님(명시). 필요 시 교내 서버 접근제어로 보강.

## 계산 (grade.mjs)
- **도달률** = 요소점수 / 요소만점 × 100 (요소별, 0~100%).
- **과목 총점(반영)** = Σ (요소점수/만점 × 반영비율), 비율 합 100 → 0~100.
- **5등급** = 학년 전체의 과목 총점 정렬 → 누적 10/34/66/90/100% 컷. 동점은 표준 석차등급 방식(그룹 대표 누적위치).
- 순수함수 분리, 단위 테스트(100명 균등분포 → 1등급 상위10명, 동점, 소규모 코호트).

## 입력 파일 기본안 (실제 샘플로 확정)
- **과목당 엑셀 1개**, 열: `학년 | 반 | 번호 | 수행 | 중간 | 기말` (없는 요소 열은 비움).
- 요소·반영비율·만점은 `config/subjects.json`:
```json
{
  "국어": { "components": {
    "수행": { "weight": 40, "max": 40 },
    "중간": { "weight": 30, "max": 100 },
    "기말": { "weight": 30, "max": 100 }
  }},
  "체육": { "components": { "수행": { "weight": 100, "max": 100 } } },
  "음악": { "components": {
    "수행": { "weight": 60, "max": 60 },
    "기말": { "weight": 40, "max": 100 }
  }}
}
```
- 빌드 검증: weight 합=100, 엑셀 요소 열 = config 요소 일치, 점수 ≤ max.
- ⚠️ 실제 엑셀 샘플 받으면 열/시트 구조 확정 후 파서 조정.

## 학생 탭 (코드 입력 → 대시보드)
- 상단: 코드(마스킹 ID) + 학년.
- **자기 대비 진전 라인차트** (메인): 과목별 수행→중간→기말 **도달률(%)** 추이. 시간축 × 본인 점수만. 남과 비교 없음.
- **중간+기말 과목**: 중간→기말 **변화** 강조 (변화량/방향 표시). 하강도 비난 색 금지 — 중립 프레이밍.
- 과목 카드: 5등급 뱃지(참고), 과목 SVG 아이콘, 도달률 미니 스파크라인.
- (phase 2) 루브릭 기준 대비 체크리스트.
- **숨김**: 전체 분포/위치, 석차, 백분위, 반/번호, 타학생 비교.

## 교사 탭 (비밀번호 게이트 → 진단 차트)
- **히스토그램**: 과목별 총점 분포 모양. 이봉분포(두 그룹) 감지 → 차별화 수업 신호.
- **상자그림(box plot)**: 산포·이상치. 표준편차 큼 = 이질 학급 → 소집단/차별화.
- **5등급 분포**: 등급별 인원.
- 목적 = 다음 수업 결정. 학생에게 직접 보여주는 용도 아님(원칙 명시 배너).
- (phase 2) 문항별 정답률 막대 + 난이도지수(0.7 초과 천장효과 / 0.3 미만 바닥효과) — [[문항분석]] 연결.

## 차트 (Chart.js) — 색은 전부 그린 팔레트, `docs/design.md §7`
- 진전 라인 (학생): 라인 `--brand`, 포인트 강조. 변화 상승/하강 색은 중립(비난 색 금지).
- 히스토그램 (교사): 막대 `--green-300`, 본인/강조 구간 `--green-600`. `chartjs-plugin-annotation`.
- 상자그림 (교사): `@sgratzl/chartjs-chart-boxplot` 플러그인.

## 의존성
`vite`, `xlsx`(SheetJS), `chart.js`, `chartjs-plugin-annotation`, `@sgratzl/chartjs-chart-boxplot`.

## 검증 (end-to-end)
1. 더미 `data/*.xlsx` + `config/subjects.json` (예: 100명, 중간·기말 있는 과목 포함).
2. `node scripts/build-data.mjs` → `students.json`/`cohort.json` 생성. 등급 컷·도달률·중간→기말 변화 수동 확인.
3. `grade.mjs` 단위 테스트(균등분포·동점·소규모).
4. `vite build` 후 서빙:
   - 학생 탭: 코드 입력 → 진전 라인·5등급 뱃지 표시, **분포/석차/백분위/반번호 미노출** 확인.
   - 교사 탭: 비밀번호 후 히스토그램·상자그림 로드, 학생 식별정보 없음 확인.
